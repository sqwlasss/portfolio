What this form actually does

This is a static website. There is no server behind it, so it cannot post your message anywhere. Instead it checks the fields, then opens your own email app with the message already written and addressed to me. If your browser has no email app set up, nothing will open, so my address is printed above for you to copy.

I would rather say that plainly than have a form that looks like it sends and quietly throws your message away.
